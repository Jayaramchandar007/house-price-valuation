# House Price Valuation & Market Explorer

A Streamlit application built from the Bengaluru house-prices dataset.

## Run locally
1. Put `bengaluru_house_prices.csv` in the same folder as `app.py`.
2. Install Python packages:
   ```bash
   pip install -r requirements.txt
   ```
3. Start the app:
   ```bash
   streamlit run app.py
   ```

The app includes dataset filters, exploratory plots, neighborhood comparison, a Random Forest price estimate, test-set metrics, and filtered-data download.

## Files
- `app.py`: application
- `requirements.txt`: dependencies
- `bengaluru_house_prices.csv`: original dataset (included in this package)
